# 餐盘 Canting

**用陪伴让吃饭变有趣的饮食记录 APP。**

你好好吃饭，桌上的小宠物就慢慢长大；你不好好吃饭，它会蔫给你看。饮食记录不再是对着表格打卡，而是养一只等着你喂饭的小家伙。

## 核心功能

- **饮食记录**：快速记下每一餐，自动汇总当日完成度
- **宠物陪伴**：首页常驻一只专属宠物，根据你的吃饭情况做出反应
- **成长进化**：从蛋开始，攒够成长值依次孵化、幼年、成年，每次进化都有动画庆祝
- **营养分析**：记录的同时看到营养摄入情况
- **桌面小组件**：不打开 APP 也能在桌面看到宠物状态和今日完成度

## 测试版 V1 包含什么

- 蛋初始状态：新玩家从一颗蛋开始，先选一只心仪的宠物
- 进化动画：蛋 → 幼年 → 成年的完整成长链路，进化瞬间有专属动画
- 3 种宠物可选：猫、狗、仓鼠
- 4 档活力状态：宠物的形象、气泡文案会随你近期的吃饭情况变化
- 像素风 UI：全套像素画风格的界面与宠物形象
- 桌面小组件（Android）：4×2 默认尺寸，展示宠物形象、活力标签和今日完成度

## 适合谁用

- 想养成"好好吃饭"习惯，但坚持不了打卡表格的人
- 喜欢宠物养成类玩法，希望记录工具有点温度的人

## 安装与试用

1. 在手机上找到 `canting_v0.1.0-beta.apk`，点击安装（需要允许"安装未知来源应用"）
2. 目前仅支持 Android；首次打开按引导完成：欢迎页 → 选择宠物 → 进入首页
3. 进入首页会看到你的宠物蛋，通过记录饮食积累成长值，推动它孵化、长大
4. 建议同时添加桌面小组件：长按桌面空白处 → 添加小组件 → 找到"餐盘"

> 注意：删除旧版本小组件后需重新添加，才能看到新版布局。

## 已知限制与后续规划

**已知限制（测试版如实说）：**

- 饮食数据目前是本地 mock 数据，营养分析基于内置数据，不代表真实摄入
- 仅支持 Android，iOS 版尚未开始
- 宠物交互以"看"为主，可玩性有限

**后续规划：**

- 接入真实菜品识别与营养数据库
- 更多宠物种类与互动玩法
- iOS 版本

## 技术栈

Flutter + Provider 状态管理 + 像素风美术资源；Android 桌面小组件为原生实现。
