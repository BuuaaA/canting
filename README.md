# 餐盘 Canting

用养成游戏的方式，让你不知不觉吃更均衡。

## 这是什么

餐盘是一款宠物陪伴式的饮食健康 APP。你每天记录吃了什么，你的小宠物就会跟着一起成长——吃得越均衡，它长得越好。

不催你节食、不算卡路里，而是用"养宠物"的轻松方式，帮你建立对"均衡饮食"的感知，慢慢改善饮食结构。

## 核心玩法

- 🐣 从一颗蛋开始：新用户的宠物是一颗蛋，记录餐食帮它破壳而出
- ✨ 进化成长：蛋 → 幼年 → 成年，每次跨越阶段都有进化动画
- 🐱 3 种伙伴可选：猫、狗、仓鼠，挑一个陪你吃饭
- 📊 六大营养素可视化：一眼看懂今天谷物、蔬菜、蛋白质等吃够了没
- 🍽️ 饮食记录：轻松记录每餐，不用算卡路里
- 💬 宠物会说话：不同状态下宠物有不同反应和对话
- 📱 桌面小组件：不用打开 APP 也能看到宠物状态

## 这个测试版包含什么

测试版 V1 是一个可体验的原型，核心流程已跑通：

- 完整的新手引导（5 步）
- 宠物从蛋开始的成长系统
- 进化动画（蛋→幼年→成年）
- 首页饮食完成度展示
- 像素风格 UI

⚠️ 注意：当前餐食数据为 mock 数据，菜品识别等功能尚未接入。

## 适合谁用

- 想改善饮食结构，但讨厌算卡路里的人
- 喜欢宠物养成游戏的人
- 想要一个轻松的方式提醒自己好好吃饭的人

## 安装试用

1. 下载 Release 中的 APK 文件到安卓手机
2. 点击安装（可能需要允许"未知来源"安装）
3. 打开 APP，完成新手引导，开始你的陪伴之旅
