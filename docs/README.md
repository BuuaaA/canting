# 项目文档

仓库文档按用途分为以下几类：

## 当前参考文档

`docs/` 根目录保存产品和技术参考资料，例如核心引擎接口、数据结构和模块说明。

## 开发资料

`dev-docs/` 保存开发过程中的模块设计、实现记录、构建资料和验收证据。这里的内容主要服务于开发、维护和问题追溯。

## 历史资料

`docs/archive/` 保存早期产品规划、阶段开发指令和历史交接文档。这些文件用于保留项目上下文，不作为当前版本的使用入口。

## 文档约定

- 新增面向用户的内容放在根目录 `README.md` 或单独的产品文档中。
- 新增技术说明放在 `docs/`，并使用清晰的英文或拼音文件名。
- 开发过程记录、验收记录和交接资料放在 `dev-docs/`。
- 已结束阶段的指令、方案和交接资料放入 `docs/archive/`，避免与当前开发入口混在一起。
