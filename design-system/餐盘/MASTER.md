# 餐盘 UI Design System

> Flutter 应用内界面的全局视觉规范。页面级文件存在时，以页面级规则为准。

## 设计方向

- 气质：轻松、可爱、有生活感的田园像素游戏
- 参考边界：参考生活模拟游戏的温暖节奏，不复制具体角色、图块或 UI 素材
- 核心视觉：有限色板、硬边像素、分层描边、木牌/草地/天空等抽象场景
- 信息原则：先展示宠物和“今天该做什么”，再展示分析数据

## 字体

- 中文正文：系统无衬线字体，保证长文本可读
- 数字、百分比和极短标签：`CantingPixel`（Press Start 2P）
- 不对中文正文强制像素字体
- 字号不随视口宽度缩放，字距统一为 0

## 几何与层级

- 基础网格：4px
- 页面水平边距：16px；宽屏内容最大宽度：680px
- 面板圆角：0-4px，禁止大圆角胶囊卡片
- 面板边框：2px 深色主描边 + 1px 内高光
- 阴影：仅使用 2-3px 的无模糊硬阴影
- 页面段落不做悬浮卡片；卡片只用于可点击项目、状态板和工具区

## 组件

- 主要按钮：48px 高，2px 描边，2px 硬阴影，按下时阴影收回
- 图标按钮：至少 44x44px，统一使用 Material Symbols
- 输入框：方角浅底、2px 边框，聚焦时绿色外框
- 进度条：使用离散像素格，不使用圆润渐变条
- 底部导航：木质/纸张工具栏感，选中态为实色方形图标底
- 对话气泡：方角、短尾巴、无模糊阴影

## 动效

- 每屏最多 1-2 个持续动画，优先留给宠物 sprite
- 点击反馈 80-120ms，页面切换 180-240ms
- 入场使用 ease-out，离场使用 ease-in
- 始终遵守 `MediaQuery.disableAnimationsOf(context)`
- 不使用漂浮、视差、故障闪烁、霓虹辉光

## 响应式与无障碍

- 最窄验收宽度：375px
- 所有触控目标至少 44x44px，相邻目标至少间隔 8px
- 使用 `LayoutBuilder` 处理网格和宽度变化
- 自绘图形必须有 `Semantics`
- 颜色之外同时使用文字、图标或形状表达状态
- 正文与背景对比度至少 4.5:1

## 禁止项

- 禁止 emoji 充当图标或状态反馈
- 禁止紫蓝渐变、玻璃拟态、发光边框、模糊色块
- 禁止整页同色系和大面积米黄/棕色
- 禁止默认 Material 圆角卡片堆叠
- 禁止装饰性大标题挤占首屏
- 禁止复制《星露谷物语》的角色、图块或界面素材

## 页面重点

- 首页：宠物场景是首屏主角；膳食数据表现为“今日任务板”
- 记录：像素账本，编辑操作明确、紧凑
- 历史：月历像挂历，不用圆形日期气泡
- 设置：分组清单像工具箱，不堆叠卡片
- 引导：保持五步流程，每页只有一个主任务
