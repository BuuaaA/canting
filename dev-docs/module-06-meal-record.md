# 模块 06：餐食记录

**预估工时**：2h
**依赖**：模块 01, 02
**优先级**：P0

## 功能描述

餐食记录的增删改查，包括手动添加记录、查看记录详情、修改分量、删除记录。

## 涉及文件

```
lib/ui/meal/
  ├── meal_detail_page.dart       — 记录详情页
  ├── add_meal_page.dart          — 手动添加记录页
  ├── dish_search_page.dart       — 菜品搜索选择页
  └── size_selector.dart          — 分量选择器
```

## 数据模型

详见模块 01 中的 MealRecord 和 MealDish。


### 核心功能

1. **修改菜品分量**：点击菜品 → 弹出分量选择器（小/常规/大）
2. **删除菜品**：左滑删除
3. **添加菜品**：点击「+ 添加菜品」→ 搜索菜品
4. **修改备注**：点击备注编辑
5. **删除整条记录**：底部按钮，二次确认

### 二次确认弹窗

```
确定删除这条记录吗？
删除后当日膳食结构会重新计算。

[ 取消 ]  [ 删除 ]
```

## 添加记录的联动效应

添加一条记录后，以下内容自动更新：
1. 当日膳食结构（重新汇总所有菜品的份数）
2. 整体完成度
3. 宠物活力值（重新计算）
4. 宠物成长值（+10 点/餐，每日上限 30）
5. 下一餐推荐

## 删除记录的联动效应

删除一条记录后：
1. 当日膳食结构重新计算
2. 宠物活力值回退
3. 成长值不回退（只增不减原则）
4. 推荐重新计算
