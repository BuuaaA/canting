# 模块 10：个人设置

**预估工时**：2h
**依赖**：模块 01, 04
**优先级**：P0

## 功能描述

个人设置页面，用户可修改个人信息、作息习惯、外卖平台、数据管理等。

## 涉及文件

```
lib/ui/settings/
  ├── settings_page.dart          — 设置主页
  ├── profile_edit_page.dart      — 个人信息编辑页
  ├── schedule_settings_page.dart — 作息设置页
  ├── platform_settings_page.dart — 外卖平台设置页
  ├── notification_settings_page.dart — 通知设置页
  ├── data_management_page.dart   — 数据管理页
  ├── pet_management_page.dart    — 宠物管理页
  └── about_page.dart             — 关于页面
```

## 个人信息编辑

### 功能

- 修改性别、年龄、身高、体重
- 修改饮食目标
- 修改活动量
- 修改后重新计算每日建议摄入量
- 修改后当日结构和完成度重新计算

### 复用组件

- 复用初始设置 Step 1-3 的表单组件
- 预填当前值
- 保存时二次确认「修改后今日数据会重新计算，确定吗？」

## 作息设置

### 功能

- 修改早餐/午餐/晚餐时间（TimePicker）
- 修改日期切换时间（0:00 / 1:00 / 4:00）
- 修改后推荐时间相应变化

## 外卖平台设置

### 页面结构

```
← 外卖平台

选择常用平台（推荐页会显示这些平台）

☑ 美团外卖    [≡]
☑ 淘宝闪购    [≡]
☑ 京东外卖    [≡]
☐ 美团APP     [≡]

长按拖动可调整顺序

至少选择 1 个平台
```

### 功能

- 开关选择平台
- 长按拖动排序
- 至少选择 1 个（最后一个不能取消）
- 设置保存到 SharedPreferences
- 推荐详情页按此设置显示平台按钮

## 通知设置

### 功能

- 识别结果通知：开关（默认开）
- 通知权限状态显示
- 未开启权限时引导跳转系统设置
- V1.0 不包含用餐提醒和缺口提醒

## 数据管理

### 数据导出

- 导出 JSON 格式
- 内容包括：用户设置、所有餐食记录、宠物状态
- 使用系统分享面板分享文件
- 文件名：`canting_backup_YYYYMMDD.json`

### 清除数据

- 二次确认弹窗
- 警告：所有记录将被删除，不可恢复
- 清除内容：所有餐食记录、宠物状态重置
- 保留内容：用户设置（身体数据/目标/活动量等）
- 清除后回到首页（空状态）

## 宠物管理

- 宠物基本信息展示
- 进化记录时间线
- 重命名宠物（弹窗输入）
- V1.0 不支持换宠物
