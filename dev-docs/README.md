## 膳食指南权威数据

所有营养计算和推荐均基于《中国居民膳食指南（2022）》。

- 数据说明文档：`assets/data/dietary_guidelines_data.md`
- 结构化数据：`assets/data/dietary_guidelines.json`

### 核心修正（相对 V0.6）

| 项目 | V0.6 | V1.0 |
|------|------|------|
| 谷薯类目标 | 5~8 份 | **4~6 份**（2022版下调） |
| 坚果定位 | 每日目标 | **每周目标，大豆优先** |
| 蔬果分类 | 合并 | **展示合并，分开追踪** |
| 奶类归属 | 单列 | **归入蛋白质大类** |
