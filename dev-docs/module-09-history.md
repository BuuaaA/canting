# 模块 09：历史记录

**预估工时**：2h
**依赖**：模块 01, 02, 07
**优先级**：P0

## 功能描述

历史记录页面，以日历视图展示用户的记录历史，每天用不同颜色的圆点表示当天的宠物活力状态。

## 涉及文件

```

  ├── history_page.dart           — 历史记录主页面（日历视图）
  ├── calendar_view.dart          — 日历组件
  └── day_detail_page.dart        — 单日详情页
```

### 日历组件

**每一天显示**：
- 日期数字
- 底部小圆点表示活力值状态
  - 绿色（≥ 60）：吃得不错
  - 黄色（40-59）：一般
  - 红色（< 40）：不太好
  - 灰色/无点：当天无记录

**月份切换**：
- 左右箭头切换月份
- 中间显示年月
- 不能切换到未来月份

**点击日期**：
- 有记录 → 跳转到日详情页
- 无记录 → 不跳转（或提示"当天没有记录"）

### 补录功能

- 可补录最近 7 天内的记录
- 补录流程同添加记录
- 补录后当天的活力值和完成度重新计算
- 补录的成长值按记录日期算（不影响今日上限）

## 数据查询优化
