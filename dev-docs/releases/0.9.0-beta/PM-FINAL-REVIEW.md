- Widget：AppState 使用注入本地时钟；7 日窗口不存在或 error 时不认证 record_date。保存、编辑、删除和前台恢复重算窗口并串行同步；原生同时核对本地日期和 UTC 偏移，旧字段缺失、跨日、回拨及偏移改变均过期。过期隐藏数值，保留布局使用明确日期，系统刷新不承诺午夜准点。
