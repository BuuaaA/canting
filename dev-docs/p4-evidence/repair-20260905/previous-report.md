## 2. 数据、政策与用户体验

数据库仍 v4，没有 schema/身份键迁移，没有重写旧餐、个人记忆、奖励凭证或 P3 提醒。requestId 和 warning 是内存草稿字段；原生每项 requiresConfirmation 进入既有 FoodObservation manual/未知语义。识别不会自动保存整餐。原名、品牌、本次明确规格、来源和未知贡献沿用 P2。

FoodMatchPolicy 位于 `lib/core/models/local_food.dart`：候选相似度0.7，自动方法 exact/local_exact/knowledge_variant_exact。近似命中仍为候选；未降低任何阈值。未增加真实品牌白名单、联网、AI、遥测、菜库或推荐准入。

`三分糖→low`、`正常糖→regular` 仅补订单措辞抽取。由于名称规范化移除这两个规格词，含旧原始名称的记忆可由既有 raw_names 路径匹配；不迁移历史记录。跨品牌、清空商家、本次规格优先、删除记忆和重开 SQLite 继续由完整 P2/P3 测试保护。

成功/空/失败页保留手动补菜。空/失败显示重选图片及手动添加；成功仍可修改商品。返回有修改时确认放弃。未确认项保存仍需明确保留未知，不创建虚构的确认记忆。
