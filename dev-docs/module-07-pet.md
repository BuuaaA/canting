# 模块 07：电子宠物系统

**预估工时**：3h
**依赖**：模块 01, 03
**优先级**：P0

## 功能描述

电子宠物是产品的核心差异化功能。宠物的活力值反映用户近期饮食质量，成长值记录用户的坚持，通过陪伴感提升用户粘性。

## 宠物状态机

### 状态属性

```dart
class PetState {
  final String petType;      // cat / dog / hamster
  final String name;
  final String stage;        // baby / junior / adult
  final double vitality;     // 活力值 0-100，下限 15
  final double growth;       // 成长值，只增不减
  final int petCountToday;   // 今日摸摸头次数
  final DateTime lastPetTime; // 上次摸摸头时间
}
```

### 活力值计算

**基础公式**：
```
vitality = 基础分(60)
         + 蔬菜达标 ? 15 : 0
         + 蛋白质达标 ? 10 : 0
         + 主食达标 ? 5 : 0
         + 水果达标 ? 5 : 0
         + 大豆坚果达标 ? 5 : 0
         - 油脂超标(>150%) ? 10 : 0
         + 今日记录>=2餐 ? 5 : 0
```

**达标定义**：当前摄入量在目标的 80%-120% 之间。

**上下限**：最高 100，最低 15（永不归零）。

**时间衰减**：
- 如果超过 24 小时没有新记录，活力值每天下降 5 点
- 最低降到 15
- 有新记录后重新计算

### 成长值计算

**获取方式**：
- 每记录 1 餐：+10 点
- 当日饮食达标（完成度 > 80%）：额外 +5 点
- 摸摸头：+1 点（每日上限 3 次）
- 每日总上限：+30 点

**特性**：
- 只增不减
- 删除记录不扣成长值
- 跨日期不重置

### 进化阶段

| 阶段 | 成长值阈值 | 说明 |
|------|-----------|------|
| baby（幼年） | 0-49 | 初始形态 |
| junior（少年） | 50-199 | 第一阶段进化 |
| adult（成年） | 200+ | 最终形态（V1.0 到此） |

**进化触发**：
- 添加记录后检查成长值是否跨过阈值
- 是 → 触发进化动画 + 更新 stage
- 进化动画全屏展示，不可跳过

## 宠物对话气泡

### 文案生成逻辑

根据以下因素动态选择文案：
1. 宠物当前活力值状态（开心/一般/不太开心）
2. 当日饮食情况（各分类缺口）
3. 时间段（早上/中午/下午/晚上/深夜）
4. 特殊事件（刚记录、刚进化、首次使用）

### 文案模板

```dart
// 按场景分类的文案库
```

### 文案选择逻辑

```
优先级从高到低：
1. 刚进化 → 进化文案
2. 刚记录 → 根据记录结果选文案
3. 晚上（22点后） → 晚安文案
4. 无记录 → 无记录文案
5. 有记录但蔬菜不够 → 蔬菜文案
6. 有记录但蛋白不够 → 蛋白文案
7. 整体不错 → 开心/鼓励文案
```

## 摸摸头互动

### 规则

- 冷却时间：4 小时
- 每日上限：3 次
- 每次奖励：+1 成长值
- 冷却中点击：显示气泡「已经满足啦，等会儿再摸～」

### 交互

- 点击宠物 → 播放摸摸头动画（手从上方降下，宠物眯眼）
- 对话气泡弹出「摸摸头舒服～」
- 成长值 +1（小动画提示）

## 宠物与餐食联动

```
添加餐食 → 重新计算活力值 → 成长值+10 → 检查进化 → 更新UI
删除餐食 → 重新计算活力值 → 成长值不变 → 更新UI
修改分量 → 重新计算活力值 → 更新UI
```
