# 中国居民膳食指南（2022）核心数据提取

> 来源：《中国居民膳食指南（2022）》中国营养学会编著
> 提取目的：为「餐盘」APP 提供膳食结构推荐的权威数据依据
> 提取原则：只提取 APP 计算和推荐所需的核心数据，非相关内容不收录

## 一、核心确认

### 1.1 五大类食物分类（APP 分类体系依据）

平衡膳食由五大类食物组成：

| 序号 | 类别 | 包含内容 | APP 对应分类 |
|------|------|---------|-------------|
| 1 | 谷薯类 | 谷类（含全谷物）、薯类、杂豆 | 谷薯类 |
| 2 | 蔬菜和水果 | 各类蔬菜、水果 | 蔬菜水果（合并展示） |
| 3 | 动物性食物 | 畜、禽、鱼、蛋、奶 | 蛋白质类（含奶） |
| 4 | 大豆类和坚果 | 大豆及其制品、坚果 | 大豆坚果类 |
| 5 | 烹调油和盐 | 各种烹调油、食盐 | 油脂盐（不做份推荐，仅提醒） |

> **注意**：指南原文是五大类，不是六层宝塔。宝塔是可视化呈现方式。
> 奶类在指南中归入「动物性食物」大类，但实操中常单列。APP 设计时将奶类归入蛋白质类。

## 二、成年人每日推荐摄入量

### 2.1 轻身体活动水平成年人（18-49岁）核心推荐

基于 2000 kcal 能量水平（成年男性轻活动约 2200 kcal，女性约 1800 kcal，取中间值）：

| 食物类别 | 每日推荐量 | 备注 |
|---------|-----------|------|
| **谷薯类** | 200~300g | 其中全谷物和杂豆类 50~150g；薯类 50~100g |
| **蔬菜** | ≥ 300g | 深色蔬菜应占 1/2 |
| **水果** | 200~350g | 果汁不能代替鲜果 |
| **动物性食物** | 120~200g | 含鱼、禽、蛋、瘦肉 |
| **奶类** | 300ml 以上液态奶 | 或相当量的奶制品 |
| **大豆及坚果** | 25~35g | 大豆 + 坚果合计 |
| **烹调油** | 25~30g | - |
| **食盐** | ≤ 5g | - |
| **添加糖** | ≤ 50g，最好 ≤ 25g | - |

## 三、「份」的定义与换算

### 3.1 膳食指南中的「份」概念

膳食指南中的「食物交换份」概念：**每份食物提供约 90 kcal 能量**，同类食物可以互相交换。

### 3.2 各类食物每份对应重量

| 类别 | 每份重量 | 举例 |
|------|---------|------|
| 谷薯类 | 25~50g | 1 份米饭 ≈ 50g 生米（约 150g 熟饭） |
| 蔬菜类 | 500g | 1 份蔬菜 ≈ 500g 白菜/西兰花等 |
| 水果类 | 200~350g | 1 份苹果 ≈ 200g |
| 肉蛋类 | 50g | 1 份鸡胸肉 ≈ 50g |
| 大豆类 | 25g 大豆 | 1 份大豆 ≈ 25g 干大豆 ≈ 75g 豆腐 ≈ 350g 豆浆 |
| 坚果类 | 10g | 1 份坚果 ≈ 10g |
| 奶类 | 250ml | 1 份牛奶 ≈ 250ml |
| 油脂类 | 10g | 1 份油 ≈ 10g |

### 3.3 APP 的「份」设计建议

**APP 不使用传统的「食物交换份」（90kcal/份）**，原因：
1. 不同类别每份能量差异大，用户难以理解
2. APP 的核心目标是「膳食结构」而非「能量计算」
3. 外卖场景下，份量估算本来就有误差

**APP 改用「膳食宝塔目标份」**：
- 直接以每日推荐量为基准，设为「N 份」
- 用户每吃一顿，估算吃了几份
- 目标是让当天各类食物的份数接近推荐目标

**建议的每日目标份数**（基于 2000 kcal 能量水平）：

| 类别 | 每日推荐量 | 目标份数 | 每份对应 |
|------|-----------|---------|---------|
| 谷薯类 | 200~300g | **4~6 份** | 1 份 ≈ 50g 谷薯（约一小碗饭） |
| 蔬菜类 | 300~500g | **4~5 份** | 1 份 ≈ 80g 蔬菜（约一小碟） |
| 水果类 | 200~350g | **2~3 份** | 1 份 ≈ 100g 水果（约半个苹果） |
| 蛋白质类 | 120~200g 肉蛋 + 300ml 奶 | **4~6 份** | 1 份 ≈ 50g 肉蛋 或 150ml 奶 |
| 大豆坚果类 | 25~35g | **2~3 份** | 1 份 ≈ 10~15g |
| 油脂 | 25~30g | （仅监控） | - |

> 重要：APP 的「份」是**相对概念**，不是精确计量单位。
> 核心目的是帮用户感知「我今天蔬菜吃够了吗？」而不是精确计算摄入量。

## 四、关于大豆和坚果的重要澄清

### 4.1 指南原文怎么说

- 「经常吃全谷物、大豆制品，**适量吃坚果**」
- 「平均每天摄入大豆和坚果 **25-35g**」
- 坚果推荐量：**每周 50~70g**（平均每天约 10g）
- 大豆推荐量：**每天 15~25g**（按不同年龄/能量水平）

### 4.2 关键结论

**大豆和坚果是合并推荐的，但优先级不同：**
1. **大豆是「经常吃」**——豆制品是平衡膳食的重要组成部分，推荐每天吃
2. **坚果是「适量吃」**——坚果是有益补充，但不是必需品，每周 50-70g 即可

### 4.3 对 APP 设计的影响

**问题修正：APP 不应该让用户觉得「每天必须吃坚果」**

正确的呈现方式：
- 大豆坚果合并为一个分类目标（25-35g/天）
- 推荐时**优先推荐豆制品**（豆腐、豆浆等）
- 坚果作为可选补充，不强调「必须完成」
- 如果用户某天没吃坚果，但吃了豆制品，也应该算达标

## 五、一日三餐的食物分配

### 5.1 三餐能量分配

- 早餐：30%
- 午餐：40%
- 晚餐：30%

### 5.2 三餐食物品种数分配

- 早餐：3~5 种
- 午餐：4~6 种
- 晚餐：4~5 种
- 零食：1~2 种

### 5.3 食物多样性目标

- 每天摄入 ≥ 12 种食物
- 每周摄入 ≥ 25 种食物

### 5.4 各类别在三餐中的分布建议

| 类别 | 早餐 | 午餐 | 晚餐 |
|------|------|------|------|
| 谷薯类 | ★★★ 主食 | ★★★ 主食 | ★★ 适量 |
| 蔬菜 | ★★ 适量 | ★★★ 多吃 | ★★★ 多吃 |
| 水果 | ★★ 可以吃 | ★ 适量 | ★ 少量 |
| 蛋白质 | ★★ 蛋/奶 | ★★★ 肉/鱼 | ★★ 适量 |
| 大豆坚果 | ★ 豆浆/坚果 | ★☆ 适量 | ☆ 少量 |

> 注：★ 越多表示该餐推荐多吃这类食物

## 七、APP 推荐规则库

### 7.1 结构优化规则

| 场景 | 推荐方向 |
|------|---------|
| 蔬菜不足 | 下一顿优先推荐蔬菜类菜品 |
| 水果不足 | 建议加餐吃水果，或推荐有水果的餐 |
| 蛋白质不足 | 推荐鱼、禽、蛋、瘦肉等菜品 |
| 谷薯过多 | 建议减少主食量，换成蔬菜 |
| 大豆坚果不足 | 优先推荐豆制品（豆腐、豆浆等） |
| 油脂过多 | 推荐清淡做法（蒸、煮、凉拌） |
| 肉类过多 | 下一顿减少肉类，增加蔬菜 |

### 7.2 餐次适配规则

| 餐次 | 适合推荐 | 不适合推荐 |
|------|---------|-----------|
| 早餐 | 谷薯 + 蛋/奶 + 少量水果 | 大量肉类、油腻食物 |
| 午餐 | 均衡搭配，各类都有 | - |
| 晚餐 | 多蔬菜 + 适量蛋白 + 少主食 | 大量主食、油腻食物 |

### 7.3 多样性鼓励规则

- 连续两顿吃同类食物 → 提醒「换个种类吧」
- 当天食物种类 < 8 种 → 鼓励多尝试不同食物
- 本周食物种类 < 15 种 → 提醒尝试新的食物

## 九、坚果问题的明确回答

**问：现在这个版本打开以后每天都要吃坚果，这科学吗？**

**答：不科学。**

膳食指南推荐的是：
- 大豆 + 坚果合计每天 25~35g
- 其中坚果是**每周 50~70g**（平均每天约 10g），不是每天必须吃
- 大豆是推荐经常吃的，坚果是「适量」「有益补充」

**APP 正确做法**：
1. 大豆和坚果合并为一个目标
2. 用户吃了豆制品（豆腐、豆浆等）就算进度
3. 坚果是加分项，不是必选项
4. 推荐时优先推荐豆制品，坚果作为可选
